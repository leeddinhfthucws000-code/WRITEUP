# Comprehensive Guide to Windows Artifacts for Digital Forensics 
## Overview
Windows Artifacts are pieces of data, files, registry entries, or logs automatically generated by the Windows operating system during routine usage. They provide crucial evidence for forensic investigators to reconstruct user activities, detect security breaches, analyze malware execution, and trace unauthorized system access.

---
## 1. System & User Configuration Artifacts

### 1.1. Windows Registry (System-wide)
* **Description:** It is the storage location for computer activity. According to Microsoft, the Registry contains information that Windows continuously references during operation, such as profiles for each user, applications installed on the computer, types of documents that each user can create, property sheet settings for folders and application icons, hardware existing on the system, and ports currently in use. The Windows Registry consists of 5 main keys, categorized by container area and structured in a tree-like hierarchy:
* **5 main keys:**
  * `HKEY_CURRENT_USER (HKCU)`: Settings for the currently logged-in user (desktop background, theme, recent files, network maps, run history, user startup programs).

  * `HKEY_USERS (HKU)`: Contains profiles for all users who have ever logged into the system.
  * `HKEY_LOCAL_MACHINE (HKLM)`: System-wide settings applied to all users (hardware info, drivers, system services, installed applications, persistence entries, time zone, USB connection history).

  * `HKEY_CLASSES_ROOT (HKCR)`: Defines file associations and default file handlers.
  * `HKEY_CURRENT_CONFIG (HKCC)`: Real-time hardware configuration profiles (display settings, resolution, active devices).

* **Forensic Value:** Essential for identifying user actions, detecting connected USB devices, identifying persistence mechanisms, and tracking system alterations.
* **Access Method:** Run `regedit` via the Windows Run dialog (`Win + R`).
### 1.2. NTUSER.DAT (User-specific Registry)
* **Description:** Located at `C:\Users\<Username>\NTUSER.DAT`. Holds individual registry settings for a specific user.
* **Forensic Value:** Allows investigators to analyze individual user behavior, execution history, and preferences without processing the entire system hive. 

### 1.3. Shellbags (Folder Browsing History - Advanced)
* **Description:** Registry keys located in `UsrClass.dat` and `NTUSER.DAT` that store view preferences and folder interaction records in Windows Explorer. ( `C:\Users\<Tên_User>\AppData\Local\Microsoft\Windows\UsrClass.dat `)
* **Forensic Value:** Proves folder access, directory navigation, and file structure viewing—even if the folders or files have been completely deleted from the drive.

## 2. Program Execution & Process History Artifacts

### 2.1. Prefetch Files (`.pf` - Advanced)
* **Location:** `C:\Windows\Prefetch\`
* **Description:** Created automatically when an application runs for the first time to optimize future boot times.
* **Forensic Value:** Records application execution history, execution count, last run timestamp (and previous 8 execution times), and loaded DLL dependencies. Excellent evidence even if the original executable has been wiped.

### 2.2. UserAssist Key (Advanced)
* **Location:** `NTUSER.DAT` (`Software\Microsoft\Windows\CurrentVersion\Explorer\UserAssist`)
* **Description:** Tracks GUI applications launched via Start Menu or Desktop (encoded using ROT13 cipher).
* **Forensic Value:** Provides exact execution counts and last-execution timestamps for user-launched applications.

### 2.3. ShimCache & Amcache.hve (Advanced)
* **Location:** `C:\Windows\appcompat\Programs\Amcache.hve`
* **Description:** Windows Application Compatibility features used to verify software execution settings.
* **Forensic Value:** Stores file SHA1/SHA256 hashes, file paths, and file modification timestamps. Critical for tracking malware execution even if files were renamed or deleted.

## 3. File Interaction & Storage Artifacts

### 3.1. LNK Files (Shortcut Files)
* **Description:** Windows shortcuts (`.lnk`) containing metadata pointing to target files.
* **Forensic Value:** Stores target file path, file size, hidden attributes, creation/modification/access timestamps, hard drive/USB volume serial numbers, and host MAC addresses.
* **Analysis Tool:** `LECmd.exe` by Eric Zimmerman.
  ```cmd
  # Single file inspection
  .\LECmd.exe -f "C:\Path\To\File.lnk"

  # Directory-wide scan (e.g., Recent files)
  .\LECmd.exe -d "C:\Users\<Username>\AppData\Roaming\Microsoft\Windows\Recent"

  # Export results to CSV
  .\LECmd.exe -d "C:\Users\<Username>\AppData\Roaming\Microsoft\Windows\Recent" --csv "D:\Output"
